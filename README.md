# Railroader Map Modding Guides

Guides to building on the Railroader 0.6 base map with the game's own Map Editor and mod files.

The base map isn't officially open for building yet, and the editor and file formats may still change during
Experimental. These guides will change with them. Corrections and suggestions are welcome as issues or pull requests.

## Guides

- [Your editing mod and your release mod](editing-mod.md): start here. Creating the mod you edit in the Map Editor,
  and how it differs from the mod you release.
- [Adding terrain tiles](terrain-tiles.md): fetching new terrain beside the base map in the Map Editor, and adding it to
  the base map with a mod.
- [Shaping the ground with terrain masks](terrain-masks.md): levelling ground on the base map for yards, industry sites
  and roads, where the terrain brushes can't be used.
- [Adding industries](industries.md): areas, industries, track spans and components in the Map Editor, changing
  base-game industries, and adding them to the base map with a mod.

## Versions

Written for Railroader 0.6 (the 2026 Experimental update) and its built-in mod loader. Nothing here applies to Legacy
(2025.1 and earlier) or its loaders.
